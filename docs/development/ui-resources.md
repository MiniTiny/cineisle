# UI 与资源

适用：页面、组件、主题、布局、文案、语言与资源变更。

- 用户文案使用资源键与参数，不拼接完整句子。元数据匹配词、协议值和语言自称是不同语义，不机械搬入翻译资源。
- 颜色、字号、间距和圆角采用主题/组件中的语义角色。字幕样式、视频画布、系统栏和普通页面分别管理，不全局替换所有黑色或白色。
- 共享主题覆盖普通、选中、禁用、错误状态，处理动态主题与 AMOLED。默认外观改变须作为明确的设计变更。
- 重复的设置行、卡片与输入模式由语义组件承接；页面负责组合。组件接口表达真实差异，不允许任意覆盖全部细节形成万能组件。
- 页面专有且清晰的比例或几何可以保留局部。响应式计算优先复用 UiLayout，不把每个尺寸都变为全局常量。
- 保留大字体、短横屏、滚动、焦点、可访问性、触控区域和加载/空/错误状态。
- 仅静态页面通过不足以验收交互；根据改动验证控件动作与状态，再验证响应式和设备表现。
- 资源文件、SVG path/viewBox 与图标生成值是声明数据，不参加全仓风格重写；生成资源按工具链专题管理。

涉及偏好保存、异步回调、错误身份或路由模型时，按基础路由补读对应专题，不把这些规则留在视图中。
