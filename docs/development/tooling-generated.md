# 工具链与生成物

适用：构建脚本/配置、生成器/生成物、工具环境、依赖/源码锁定、版本元数据。

- 生成 API、模型、图标等从固定输入和声明生成；不手改输出掩盖漂移，修改生成器/配置后验证再生成。
- OpenAPI schema、第三方头文件、源码 SHA、补丁、ABI、SDK/API floor 与 lockfile 是可复现契约，不批量统一其常量/版本。
- 应用发布版本选定权威来源，生成客户端身份或做一致性检查；依赖版本、schema 版本、原生运行时与 Android 功能基准分别治理。
- Client/Bundle/Asset alias 等身份具有兼容意义，不随显示名称或版本机械改写。
- 工具路径采用一致的显式参数/环境覆盖、合理默认与明确报错；允许默认安装目录，不把本机绝对路径写入可复用产品/测试逻辑。
- 测试应保留实际 SDK 编译器与原有模拟边界；环境变化不能降级成假编译。
- 不输出或提交签名凭据；下载与生成产物、本地路径、日志放 `.local` 或已有忽略位置。
- 依赖升级、原生补丁变动与工具迁移独立评审，不混入行为等价常量提取或全仓格式化。

验证输入指纹、生成漂移、版本/契约一致性和实际构建。涉及工具定位时覆盖默认目录、自定义含空格路径、缺失 SDK 与 CI 配置。文档约定不表示相应自动门禁已经存在；新增检查应低误报、可复跑。
