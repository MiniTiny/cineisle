# 异步与生命周期

适用：异步副作用、定时器、任务、重试调度、并发、取消、资源释放、账号/页面/会话切换。

- 异步工作明确所属账号、页面/会话和版本；每次重要 await 后，重新核对所有权再发布结果或写入。
- 取消和晚到结果不能修改新会话，也不能确认过期意图；未知写结果不能自动等同失败或安全重放。
- 并发去重、串行化、锁和 lease 说明保护的资源及所有者；禁止用全局布尔量替代跨操作所有权。
- 定时器、HTTP、播放器、AVSession、PixelMap、文件句柄与原生对象明确创建/释放责任，覆盖异常、取消、切后台和退出。
- 调度周期、退避等待、执行窗口和交互延迟分别维护；相同数值不共用无关策略，时间调整作为行为变更另评审。
- 同步策略与调度分开，时间计算可独立验证；保留次数、退避、耗尽、认证中止、意图确认与账号恢复语义。
- 避免无界并发和轮询；已有上限、串行顺序与清理方式不能在结构重构中悄然变化。

回归覆盖虚拟时钟、重叠触发、部分失败、取消、晚到结果、账号切换及重建。修复竞争必须包含重叠执行，顺序调用通过不能证明无竞争。涉及持久化意图、错误分类或媒体会话时补读对应专题。
