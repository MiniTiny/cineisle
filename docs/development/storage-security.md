# 存储与安全

适用：Store、Preferences、Asset、凭据/PIN、文件格式/路径、持久化校验、迁移、账号隔离。

必须区分：

| 类型 | 内容 |
|---|---|
| 格式契约 | 字段、版本、Asset alias、路径/文件名、编码、分块、算法标识、旧格式读取规则 |
| 运行策略 | 重试、锁定等待、自动锁屏等行为 |
| 业务配额 | 账号/服务器数量、用户容量等产品限制 |

- 提取常量不得改变既有格式、别名和版本；升级先定义迁移、失败恢复及旧数据验证。
- 安全算法参数若参与旧格式校验，不得作为普通配置修改；不得清空凭据或降低校验来绕过兼容问题。
- 保留原子写/事务、提交顺序、回滚、崩溃恢复和多进程协调；待同步意图不能按可丢弃缓存处理。
- 可信账号/服务器与资源所有权必须贯穿最终文件、请求和异步操作；缓存键与文件路径不能跨账号混用。
- 破损元数据恢复保留必要证据，不顺带删除视频。分别声明缓存、下载、凭据和意图的可丢弃性。
- Store 的键与格式常量保留对应模块内；只共享真实跨模块契约，禁止建立全局杂项键仓库。
- 纯重构保持字段缺失补全、无效值处理、历史别名和恢复顺序不变。

验证旧格式 fixture、隔离真实文件、分块边界、写入/重命名失败、进程重建与回滚；Asset、设备锁与系统恢复分别保留设备验收。异步读写和并发事务另按基础路由读取生命周期专题。
