# 传输与错误

适用：REST/DTO、网络策略、错误身份与展示、重试/降级的错误分类。

- 传输与 DTO 映射负责协议边界；外来数据在进入业务模型前校验，明确未知字段、枚举、缺失值和损坏数据处理。
- HTTP 状态、MIME、协议路径与字段属于固定协议声明；不为消除字符串而配置化，也不在适配器内决定首页数量或推荐规则。
- 明确元数据、可选预览、海报、发现、媒体引擎和系统下载的超时来源、单位、上限与覆盖关系，不承诺一个配置控制全部网络行为。
- 机器分类与用户展示分离：错误有稳定身份和必要的结构化信息，UI 最后映射为资源文案；旧错误协议迁移保留可测试的兼容入口。
- 不根据本地化文本决定认证、重试、离线回退或重放。同步、地址恢复、可选能力分别定义错误集合，不共用过宽的“可重试”判断。
- 认证、取消、数据无效、磁盘与网络错误不能混淆。特殊可重试的存储错误在所属用例明确列出。
- 未知写结果不得自动当作未写入而重放；保持请求确认、幂等与身份约束。
- 可选能力允许有界降级，须明确降级范围、资源清理和可观察失败；不能吞异常后伪装完成。
- 错误与日志不记录令牌、密码、完整鉴权 URL 或敏感响应体。

改变请求重放、超时任务、取消或副作用时补读异步与生命周期；改变错误文案资源时补读 UI 与资源。行为回归覆盖认证/网络/磁盘/取消矩阵和实际请求数量。
