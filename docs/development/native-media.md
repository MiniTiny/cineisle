# 原生与媒体

适用：C++/N-API、播放器、字幕、解码、媒体资源上限、平台能力。

- 平台能力与门槛以本机 SDK 声明、固定运行时清单和实际探测验证；UI eligibility 不能替代库加载/能力探测。
- 应用最低 API 与可选引擎最低 API 分别维护，不通过降低门槛或静默切换引擎隐藏失败。
- 产品倍速/选项集合与引擎可接受范围可以不同，必须有明确映射。平台 enum 转换留在适配器，原生入口独立拒绝越界。
- 时间区分秒、毫秒、ticks；几何区分 vp、px、视频源尺寸；容量区分 Bytes、MiB、UTF-16 code units、UTF-8 bytes、runs、pixels。
- ArkTS/C++ 的共享契约采用固定声明生成或独立声明加一致性回归；两端都保留输入校验。
- 传输字节、解析复杂度、渲染预算保护不同阶段，不因数值接近而合并。字幕格式、字符编码、ARGB 通道顺序与取整保持原语义。
- 保留画布/像素/并发上限、字体来源、缓冲区所有权和失败清理。N-API type tag、ABI 和算法系数在所属模块固定声明并说明依据。
- 协议换算、离线进度和字幕语料中的固定基准值不可夹带调参；需要行为变化时另立规格。

验证多字节文本、N−1/N/N+1、非重叠长字幕、同时出现的复杂字幕、极端画布、原生参数和释放路径。SDK fixture、原生编译与 HAP 不能替代实际视频/字幕渲染或设备会话验收。异步媒体状态与会话交接另读生命周期专题。
