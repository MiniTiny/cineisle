# 测试与验收

适用：修改测试/fixture，新增功能、修复、行为等价重构。

## 实施前与执行中

- 列出允许改变的结构、禁止改变的行为、关键输入输出、副作用/顺序、错误分支、历史样例及相关回归。
- 基线与验收运行期间不得同时编辑被测文件；记录对应提交或工作区快照。中断、零用例、混合源码和历史结果不计入当前通过证据。
- 测试期望独立表达规格，不能读取被测常量作为期望。固定 Android 基准、第三方语料与 fixture 保持独立。
- 为风险和真实边界补行为回归，不堆叠镜像实现测试。源码字符串断言仅用于适合静态检查的安全禁止项、生成边界与基准声明。
- 失败要查明；禁止仅删除断言、放宽期望或假编译来使结果变绿。

## 按改动选择验证

| 范围 | 验证重点 |
|---|---|
| 规则/类型 | 输入输出、阈值边界、未知值、稳定顺序 |
| 存储/格式 | 旧 fixture、隔离真实文件、故障注入、重建/回滚 |
| 异步 | 虚拟时钟、重叠工作、取消、晚到结果、账号切换 |
| 跨语言 | 字段/单位/范围一致性、两端入口独立校验、原生编译 |
| UI | 控件动作与状态、可访问性、响应式与设备表现 |

每批执行相关回归；产品代码合入前执行基础约定要求的协议、完整回归与构建。源码/桥接变化运行对应原生验证；纯文档只检查内容、链接与范围。测试数据中的假服务、端口和模拟 enum 不必全部外置，环境定位按工具链专题处理。

HAP 构建、签名安装、设备 UI、实际字幕/解码、真实 Jellyfin、Asset/系统调度与后台存活分别报告。本地结果不能替代未做的设备/服务验收；日志和证据存入 `.local`，明确未运行内容。
