# 映屿 · CineIsle 品牌规范

启用日期：2026-10-10。产品定位：HarmonyOS NEXT 私人影视库客户端。

“映”代表影像与放映，“屿”代表一座由个人收藏、观看记录与偏好构成的岛屿。CineIsle 由 cinema 与 isle 组成。名称表达拥有自己的影像空间，服务端协议仍使用 Jellyfin。

![映屿图标](../AppScope/resources/base/media/app_icon.svg)

## Logo

本次为映屿重新绘制的原创 SVG：青绿岛屿承载收藏，斜向光束表示放映，暖色光点表示故事与发现，海面弧线使形状更稳定。没有沿用旧启动图标的路径、渐变或播放图形。

唯一应用图标源为 `AppScope/resources/base/media/app_icon.svg`，108×108 viewBox；系统启动图标与启动窗口均引用 `$media:app_icon`。图形集中在中央区域，便于方形/圆形裁切。没有文本、字体、外部图片、脚本或滤镜依赖。本地渲染预览和设备截图不提交。

## 导航、详情与菜单图标

图标源文件见 `entry/src/main/resources/base/media`，以应用实际 SVG 为准。

全部图标重新绘制，统一24×24网格、1.75单位描边、圆头/圆角连接与至少1单位的外沿留白，适配现有22/24vp入口。14个导航/搜索/已看资源覆盖7种语义的active/muted状态；7个详情资源覆盖播放、预告片、下载、本机文件移除、服务器删除和收藏两态；17个管理资源覆盖设置、同步、回传、账户/服务器、退出、取消、方向、返回、新增、连接、配对、锁定/解锁、离线和保存等操作。8个播放资源覆盖暂停、下一集、画中画两态、音轨、字幕、倍速及后台听音频。几何定义位于 `scripts/generate-icons.py`，没有外部图标库、字体、图片或原vector导入。

- 首页为岛屿与水面，推荐为四向星光，媒体库为叠放片架，演员为圆润人物，更多为四点菜单。
- 搜索保留放大镜含义；已看为圈内勾选，收藏有空心/实心变化，状态可通过轮廓和界面选中底色辨认。
- 本机移除为带减号的文件；服务器删除为珊瑚色垃圾桶，形状与颜色均区分。确认、权限和操作逻辑保持现有行为。
- 导航选中态青绿 `#8DE8D2`、未选中 `#A6BDBB`、收藏暖金 `#F4CF8B`、服务器删除 `#FF9F9F`；底色与按钮同步使用深海/青绿资源。主操作背景 `#16776C` 配浅色文字。

统一色值放在 `entry/src/main/resources/base/element/color.json`，SVG生成器读取同一资源；`build.sh` 在编译前检查生成漂移。图片占位与系统栏同步深海底色，播放器仍保留黑色视频区域及字幕对比度。

图标回归通过固定几何指纹检查旧图形参数是否重新出现；指纹夹具位于 `tests/fixtures/icon-provenance.json`，无需历史 HAP 或审计归档。这项检查不等同于整个应用的许可审计。

## 菜单和快捷入口

“更多”使用岛屿Logo的账户摘要卡，并按“我的影库”“账户与偏好”“资料与同步”分组。八个常驻操作统一为圆角卡片：左侧青绿图标底座，操作名称左对齐，右侧使用原创方向指示。设置为滑杆，同步为双向回环，回传为向上箭头，账户/服务器为人物与服务器组合；退出使用暖金门与向外箭头，仍需确认。

收藏、下载和媒体库复用当前原创语义图形；首页收藏/下载快捷入口使用同一底座与配色，紧凑版本省略方向指示。普通宽度并排展示，窄屏或大字号时改为单列。图标与文字始终位于同一个原生Button中，装饰图形不单独拦截点击或增加读屏焦点。按钮及内部Row共享同一最小高度，使父容器按完整点击区计量，避免按钮溢出包裹列。按钮随字号预留两行文字空间，所有分组可滚动访问；同步中保留禁用与取消入口。

## 账户与设置页面

账户与服务器、设置共用 `BrandHeader`、`BrandHeading` 和 `BrandButton` 原生组件。返回箭头有独立44vp点击区；分组使用带青绿底座的原创图标，正文卡片采用深海底色、20vp圆角与16vp内边距。主操作使用青绿背景，移除/重置使用珊瑚色；图标和标题处于同一按钮中，装饰图形不截取点击或增加读屏焦点。

账户与服务器页区分已保存账户、已保存服务器和本机凭据；当前账户以圈勾图标及文字标记。添加、地址编辑和Quick Connect使用独立表单卡，输入项保持可见标签；地址多行框按可用高度限制尺寸。错误提示在固定位置独立滚动，限制高度，保留正文可用空间。账户/服务器操作在窄屏或大字号下改为单列。

设置页按浏览与离线、下载偏好、PIN应用锁分组。复选框保持原生交互，说明占用剩余宽度；PIN输入始终掩码并有独立标签。按钮预留两行标题并随系统字号增高，全部分组和底部操作可纵向滚动。

## 收藏、下载与媒体库页面

收藏和下载共用原创返回图标和分组卡片。收藏的筛选、清除、多选、全选及撤销操作使用同一图文按钮，取消收藏保留珊瑚色提示与确认。类型、题材与排序使用原生Select；筛选区和内容均可滚动，窄屏或大字号时操作改为单列。

下载按进行中、已完成和需处理分组，选中分类采用青绿背景；三字分类使用20vp图标和紧凑内边距，普通字号完整呈现一行。记录卡片包含状态/进度及带原创图标的播放、重试、停止或移除按钮；移除继续确认。空状态放在列表内，随内容滚动，避免短横屏挤占底部空间。

媒体库目录使用电影/片架语义图标、类型说明与原创方向图形，整张卡片为原生Button。电影/剧集库内容使用同一返回/刷新标题栏，省去重复标题；长名称随字号换行，网格保留动态列数和加载更多；短横屏卡片减少上下内边距，确保两倍字号下完整显示。媒体海报与元数据仍使用实际媒体数据。

媒体库作为“更多”下的子页面，目录标题栏提供原创返回箭头，返回“更多”；电影/剧集库内容返回媒体库目录。系统返回也遵循相同层级，PIN门禁和其他主导航页面继续使用原有返回处理。返回、搜索与刷新保留独立44vp点击区，并进行页面回调和原生点击验收。

## 播放器与播放选项

播放器控制区使用深海底色与分组卡片，视频区域保留黑色背景。返回和锁定/解锁固定在顶部，各有44vp原生点击区；锁定关闭选项并屏蔽返回，解锁入口保持可见。主控制复用原创图文按钮，播放/暂停为青绿主操作，播放选项按展开状态着色；进度滑杆、开关和选择菜单使用同一品牌色。

选项按系统播放、媒体与字幕、语言偏好、倍速与连播分组。媒体源、音轨和字幕复用`PlayerChoice`，有持续可见的图标/标签，明确显示当前选中值；选择菜单使用深海背景与青绿选中态。语言设置保留保存/恢复、忙碌禁用和持久化反馈。七档倍速按宽度换行，下一集与连播仅对单集显示；不可用画中画继续展示平台能力提示。

窄屏或大字号时主操作改为单列；整个控制与选项区独立滚动；横屏将视频与控制左右分栏，视频占剩余宽度，右侧面板按实际宽度换行，避免视频被竖向控件挤成窄条。固定解锁入口保持可见。视频Surface按原生播放器提供的实际宽高比计算尺寸，居中并留黑，避免竖屏容器拉伸画面；使用API 12的原生ArkUI布局，不依赖高版本视频缩放枚举。字幕固定在视频区域下沿，保留白字与半透明黑底；字幕覆盖层不接收触控。

## 首页、推荐与演员

首页片架使用带原创图标的分组标题，继续观看为播放轮廓、下一集为下一集图形、媒体库更新为片架；“查看全部”和失败重试使用共享图文按钮。大字号下分组标题与查看全部改为上下布局，长标题自然换行。搜索/刷新使用44vp独立原生图标入口，短横屏标题栏按实际图标与标题高度预留空间，搜索历史也保留图标与整块点击区。

推荐按“光影发现”卡片分组，发现为星光、重温为回环，当前模式使用青绿背景；窄屏及大字号切换改为单列，整组说明与空状态随网格滚动。演员筛选、人物与关注、作品与标签采用深海圆角分组，排序/标签选择有持续可见的图文标签、当前值和原生品牌菜单。人物入口为原生Button，包含头像/原创占位与方向图形，统计与标签分开放置；关注按钮采用暖金收藏图形与青绿选中背景，标签随字号增高。演员列表和详情的所有筛选与关注入口随内容滚动，固定返回保留44vp目标，短横屏不让筛选区挤占作品区。

## 电影与剧集详情

电影、剧集、季与单集共用原创返回/刷新标题栏，两个入口均为44vp原生按钮。完整片名放在可滚动的独立标题区，不叠在固定高度背景图内；原名与年份、时长、分级、评分保持实际元数据。播放与管理、媒体版本、故事与资料、版本与规格、演职人员、下一集及季度/单集采用同一深海分组卡片与原创语义图标。

详情操作复用共享左对齐图文按钮，播放为青绿主操作，已看/收藏和媒体源用青绿选中背景，移除本机文件与服务器删除保留危险文字和确认；原生确认弹窗的取消/下载使用青绿，移除/删除使用珊瑚色。普通宽屏操作并排，窄屏及大字号改为单列；版本按钮显示实际版本名。窄屏或大字号的元数据标签和值上下排列，避免标签列挤压正文。演员入口为含头像、姓名、角色与方向图形的全宽原生按钮，去除固定高头像横栏；其内容随字号增高，短横屏仍可滚动到完整点击区。剧集保留下一集与季入口，季内批量选择、全选、下载/取消统一图文按钮与青绿复选框，权限、忙碌、缓存和确认规则继续生效。

用户可见文案来自 string 资源；机器标识与版本来自 `ProductIdentity`。Jellyfin HTTP 头使用 ASCII 客户端名，鉴权格式、设备 ID、令牌、反向代理路径保持原协议行为。AVSession 的媒体标题仍取实际电影/单集名称，锁屏回到应用的 Want 使用运行时 abilityInfo。

新包名安装为独立应用，登录、缓存、下载与语言偏好不会自动从旧沙箱迁入。用户需重新连接服务器并设置偏好。

运行代码、打包资源和产品介绍已移除旧品牌名称。启动、导航和详情图标均为当前原创资源。现有项目许可证与 Jellyfin OpenAPI 信息见根目录 `LICENSE`、`THIRD_PARTY_NOTICES.md`；本次不改动其他许可。历史审计归档及真实工作区信息仅保留在本地。

## 验证方法

`tests/branding.test.cjs` 检查名称、资源连接、包版本、SVG 安全性与平台适配逻辑。`tests/original-icons.test.py` 检查 46 个资源、生成漂移、留白、状态几何、操作区分、引用、对比度及许可指纹。`tests/brand-package.test.py` 在构建后核验实际 HAP 的资源与身份。

逻辑测试使用平台模拟，静态 SVG/HAP 检查不证明设备桌面、启动页、锁屏或实际布局效果。设备和真实 Jellyfin 验收需要独立执行；截图、日志与签名包保留在本地。
