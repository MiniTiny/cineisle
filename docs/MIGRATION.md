# 映屿 · CineIsle 功能对照与迁移进展

## 当前固定基准

以 `codex/actor-experience` 的 **225fba7cb5ad68865986a96e4b62d883c1d987a0** 为功能对照基准。[source-baseline.json](source-baseline.json) 保存固定提交、相对路径与 575 个文件的 SHA-256，不包含本机工作区信息或未提交修改。

映屿使用包名 `com.cineisle.app`、原创岛屿 Logo、46 个原创 SVG 和深海青绿配色。对照范围为手机功能，未引入 Kotlin/AAR 或 Android TV 模块。验证方法与证据边界见 [验证说明](VALIDATION.md)。

## 原创视觉与布局约定

“更多”的八个常驻操作均有原创语义图标，按影库、账户偏好、资料同步分组；账户摘要使用岛屿Logo。全宽入口统一为左侧图标底座、左对齐标题、右侧方向指示，退出使用暖金提示。首页收藏/下载复用紧凑样式，窄屏或大字号改为单列。图标与标签在同一按钮内，装饰图标不拦截点击。详情操作标题在图标下方居中，保留两行空间。播放器七档倍速按可用宽度换行。更多、账户、设置、详情和人物简介的普通滚动内容顶部对齐，避免短内容产生无意的上方空白。

页面按实际窗口面积计算网格列数；窄屏或放大字体时减少列数，横屏适当增加。应用通过配置资源跟随系统字号，并把配置变化同步给已打开页面。按钮、输入框、详情标题区域和海报列表随字号预留空间；文本行距使用平台的 `fp` 缩放，避免重复放大。

登录、PIN门禁和播放器控制区可纵向滚动。首页快捷入口位于首页列表中；推荐、演员、收藏和下载筛选区在竖屏独立滚动；短横屏将筛选控件放入内容列表/网格，避免输入框比筛选区更高而始终裁切。播放器控制区独立滚动并保留视频区域。账户操作和批量操作按宽度换行，开关说明占用剩余宽度。账户列表切换到编辑/登录表单时回到顶部；Quick Connect数字代码在一行内适应可用宽度。

点击区域、原生截图与像素位置回归见 [验证说明](VALIDATION.md)。原创SVG和配色不因布局修复改变；其他设备、字体缩放和横屏需独立验收。

账户与服务器、设置页已统一为原创返回/分组/操作图标与深海卡片。账户、服务器及本机凭据分组清晰，登录/地址/配对表单有持续可见标签；设置按离线、下载及PIN分组。主操作、危险操作和禁用状态明确区分；系统字号变化通过共享组件同步，窄屏操作改为单列，错误区与多行地址编辑均限制高度。业务确认、账户隔离、偏好持久化及PIN规则继续按专项回归验收。

收藏、离线下载及媒体库目录/内容已统一为原创图文按钮与深海分组卡片。下载空状态随列表滚动，电影/剧集库内容合并重复标题，保留搜索、返回、刷新与分页，短横屏目录卡片缩减上下内边距。收藏筛选、多选/全选/撤销及确认，下载分类/播放/重试/停止/移除继续执行原业务规则；界面回归和实际下载/解码验收分别记录。

媒体库作为“更多”下的子页面，目录标题栏提供原创返回箭头，返回“更多”；电影/剧集库内容返回媒体库目录。系统返回也遵循相同层级，PIN门禁和其他主导航页面继续使用原有返回处理。返回、搜索与刷新保留独立44vp点击区，并进行页面回调和原生点击验收。

播放器与播放选项已统一为原创播放图标、青绿按钮/滑杆/选择菜单及四组选项卡片。顶部返回与锁定/解锁有固定44vp入口，锁定关闭选项并拦截系统返回；主操作按控制面板实际宽度与字号换行，横屏视频/选项左右分栏。媒体源/音轨/字幕明确显示当前选中值，偏好写入期间禁用冲突操作；视频Surface按原生实际宽高比居中留黑，避免容器拉伸；字幕固定于视频区域下沿，覆盖层不拦截触控。普通/两倍字号、窄屏与短横屏的布局回归，与合成视频解码、真实服务及系统播放生命周期分别记录。

## 多服务器、账户与 Quick Connect

账户与服务器管理入口位于登录页及“更多”。保留映屿名称、原创 Logo、图标和青绿配色；更多页可滚动，避免新增管理入口挤出屏幕。账户管理滚动区域顶部对齐，空列表与短表单不会垂直居中；服务器名称、用户名称、地址或当前状态更新时立即刷新对应卡片。

| 功能 | 当前行为 | 回归及验收边界 |
|---|---|---|
| 多服务器与多账户 | 可以仅保存服务器，或通过密码/Quick Connect 添加账户；按服务器ID与用户ID区分；重新登录更新原记录；切换前验证当前用户，网络不可达可进入该账户缓存，目标账户明确离线时不发请求 | 同用户ID跨服务器、同服务器多用户、失效令牌、缓存/离线修改隔离与保存失败回归；原生Asset和真实多服务器联调需独立验收 |
| 持久化与迁移 | 旧单会话Asset迁为服务器/账户集合；令牌与元数据均留在Asset，分块不超过1000字节，最后提交索引；串行更新，失败保留旧索引 | 中文字节边界、多块、迁移失败、提交失败、损坏/缺块回归；不将令牌放普通JSON或账户列表 |
| 地址管理 | 服务器名称、每行一个地址，最多8个，支持反向代理路径；同服务器账户共享地址；同一地址不能归属两个服务器；移除当前地址前验证替代地址 | 名称/路径、重复地址、身份不匹配、当前缓存归属不变回归；最多20服务器、40账户、集合64KB，超限明确失败 |
| 地址故障切换 | 连接故障及HTTP408/502/503/504触发候选探测；先匿名读取公开服务器ID，仅同ID允许携带令牌；密码/Quick Connect认证前也支持匿名候选选择；GET按候选顺序有界重试并共享探测；成功地址尽力持久化 | 第三地址、所有地址失效、并发失败、错误服务器、401/403/404/405/500不切换回归；POST/DELETE未知结果不自动重放，图片/视频/系统下载已建立的连接不会透明重启 |
| Quick Connect登录 | 生成代码、每5秒不重叠检查、授权后交换令牌；支持取消/页面离开、重新获取、禁用与失效提示；5分钟本机超时；Secret仅在控制器内存 | [官方授权流程](https://jellyfin.org/docs/general/server/quick-connect/)；授权前无令牌交换/持久化，晚到授权、字段异常、网络恢复回归；服务端可能更早令代码过期，未实现替其他客户端授权 |
| Quick Connect协议 | OpenAPI生成Enabled/Initiate/State/Authenticate及当前用户5个操作；10.8初始化GET，10.10初始化POST，旧操作别名固定在配置中 | 固定规范与29操作全覆盖回归；不根据405猜测方法，其他版本仍需联调 |
| 退出、移除与恢复 | 退出只移除当前凭据，其他账户保留；移除服务器需确认且移除其账户；缓存/下载/离线修改保留；可确认重置损坏账户存储，保留PIN与本机文件 | 不执行服务端注销、密码修改或删除媒体；同步、下载、写操作活跃时阻止切换；切换停止原播放，清空旧返回栈；首页订阅账户变化，旧页面、演员/推荐状态及登录晚到响应失效 |

账户安全细节与可复现检查见 [验证说明](VALIDATION.md)、[OpenAPI维护](../openapi/README.md)。系统Asset每条短敏感数据的容量依据 [OpenHarmony Asset说明](https://github.com/openharmony/security_asset)；实现用小块避免将整个账户集合写入单条记录。索引提交前被强制终止可能留下未引用的加密块，正常提交/失败会清理已知旧块，不声明安全擦除或跨资产事务能力。

## 保留的能力与差异

| 能力 | 当前状态 |
|---|---|
| Jellyfin、登录与账户 | 固定官方规范生成29操作/115类型定义，10.8/10.10路由和Quick Connect方法适配；多服务器/账户持久管理、地址验证与故障切换、密码及Quick Connect登录已接入；服务器自动发现仍未补齐 |
| 媒体库与详情 | 库目录、60条分页/搜索；电影/剧集/季/单集元数据、源规格、演职人员、继续/重播、一键播季/剧、NextUp、预告片、权限下载/服务器删除。复杂库排序/筛选、关联推荐仍有差异 |
| 播放系统 | AVPlayer/XComponent；媒体源、实际音轨、文本字幕、语言偏好、下一集连播；PiP字幕、后台听音频、AVSession/锁屏命令。没有mpv/FFmpeg或服务器转码回退；图片字幕、ASS样式、字幕导入/本地缓存、章节/TrickPlay、亮度音量手势仍未补齐 |
| 显示与设置 | 原创视觉、深色原生弹窗、PIN/离线/下载偏好和播放器语言偏好。动态主题、自定义首页、全部显示/网络设置、公开下载目录、完整手势配置仍有差异 |
| 本地存储与后台 | 原子JSON，意图队列与账户隔离；音频/同步后台租约；支持平台系统下载任务。海报离线缓存、RDB索引、大库UI线程性能、长期后台/进程恢复/文件校验仍需完善及实测 |
| 平台范围 | phone模块。TV遥控器、TV临时倍速与Android专用模块不在当前鸿蒙手机产品范围；未以空按钮模拟这些功能 |

以上“已实现”指源码和相应回归存在，不表示与Android所有能力完全一致。当前仍有明确差异，不能据构建或模拟器界面宣称全功能迁移完成。

## 对照依据

固定提交中的功能规划、手机人物/收藏/下载页面、同步与首页加载、安全设置、播放器控制锁和速度实现为功能对照依据。基准清单仅保存提交和相对路径指纹；本地审计报告、工作区快照、截图、日志与产物不随仓库分发。
